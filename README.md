# Delhi Air Quality Analysis 

**An exploratory data analysis of five years of daily air quality in Indian cities (2015 – 2020).**

How bad is Delhi's air compared with the rest of India? How seasonal is it? Does Diwali leave a
visible fingerprint? What did the 2020 lockdown do to the numbers? This project answers those
questions with ~29,000 city-days of official CPCB data, in code you can rerun with one command.

## Reproduce it

```bash
git clone https://github.com/shishir-sketch/delhi-air-quality-eda.git
cd delhi-air-quality-eda
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python -m src.download_data      # or put city_day.csv in data/raw/ by hand (see data/README.md)
python -m src.run_all            # -> figures/*.png + reports/key_findings.md
jupyter notebook notebooks/01_eda.ipynb   # the narrated version
```

No data yet? `make run-sample` runs the entire pipeline on **synthetic** data so you can see
how it works. (Output from that is *not* a finding.)

## Method notes & decisions

- **No imputation.** Pollution data is missing for real reasons (stations offline, cities joining the
  network late). Filling gaps would invent signal, so each analysis drops NaNs locally and states
  its own coverage threshold (e.g. ≥365 AQI days to rank a city; ≥240 days for an annual mean).
- **Like-for-like comparisons.** The lockdown effect compares 25 Mar – 31 May 2020 with the *same dates
  in 2019*, which roughly controls for season. Cities need ≥30 valid days in both windows.
- **Medians and tails, not just means.** Averages hide the days that matter for health, so the ranking
  shows the 95th-percentile day too.
- **Thresholds.** India's NAAQS 24-hour PM2.5 limit is 60 µg/m³ (annual 40); the WHO 2021 24-hour guideline is 15 µg/m³.
- **Diwali** is the main-day date for each year 2015–2019 (see `src/config.py`); years with too many
  missing days around the festival are skipped automatically.

## Limitations

- City values are CPCB aggregates of station readings; they hide within-city variation.
- Missingness is not random and differs by city and year, so cross-city comparisons are only as good as coverage.
- Diwali and lockdown comparisons are **associations**. Wind, temperature, rainfall and stubble burning
  are not controlled for.
- Data ends mid-2020, so it says nothing about later years.

## Ideas for extending this

- Join daily weather (wind speed, boundary-layer height) and see how much of the Delhi winter spike it explains.
- Add satellite fire counts for the October–November crop-residue burning window.
- Fit a seasonal decomposition per city and test for a statistically significant trend.
- Hourly data (`city_hour.csv`): when in the day does Delhi's air peak?
